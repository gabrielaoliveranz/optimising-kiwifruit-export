# APOPHENIA — Horticultural Export Risk Intelligence Agent

Interactive executive dashboard. Vanilla HTML/CSS/JavaScript with Chart.js and Mapbox GL JS.

## Run locally

1. Configure your Mapbox token:
   ```bash
   cp config.local.example.js config.local.js
   ```
   Edit `config.local.js` and replace the placeholder with your real public token.

2. Serve from this directory (ES modules require a server — file:// will not work):
   ```bash
   python -m http.server 8000
   ```

3. Open `http://localhost:8000/index.html`

## Testing

`assets/js/app.test.js` (18 tests: CONFIG structure, risk model, payment
engine, feed loader) runs two ways:

- **In a browser:** open `test.html` (served the same way as `index.html`
  above) for the visual Jest-style runner.
- **Headless, in CI:** `node run-tests.mjs` — the test file only ever
  exercises pure functions (no DOM/Canvas/WebGL API is touched), so it
  runs correctly under plain Node without a browser at all. Reproduces
  the same `describe`/`test`/`expect` shims `test.html` defines inline,
  so both runners execute the exact same 18 tests. Wired into
  `.github/workflows/tests.yml`.

## Architecture

```
06_simulator/
├── index.html              # Semantic HTML structure only — no inline styles or scripts
├── test.html                # Browser-based Jest-style test runner
├── run-tests.mjs             # Headless Node runner for the same tests (CI)
├── assets/
│   ├── css/
│   │   └── main.css        # Complete design system — tokens, layout, components
│   └── js/
│       ├── config.js       # DOMAIN CONFIGURATION — all supply-chain-specific values
│       ├── app.js          # CORE ENGINE — domain-agnostic rendering and calculation
│       └── app.test.js     # Unit test suite (Phase 4)
├── config.local.js         # Mapbox token (gitignored, never committed)
└── payload_live.json       # Live ETL payload (generated by api_feed.py)
```

### CONFIG / Engine separation

`config.js` exports a single `CONFIG` object containing every domain-specific value:
slider definitions, geographic coordinates, API paths, risk model weights, and UI copy.

`app.js` imports `CONFIG` and is completely domain-agnostic — it reads configuration,
renders charts, calculates risk, and binds events without any hardcoded business strings.

To port this framework to a different supply chain (e.g., dairy logistics, fisheries),
swap `config.js` without touching `app.js` or `main.css`.

## Token security

- The Mapbox token in `config.local.js` is URL-restricted in the Mapbox dashboard
- Allowed URLs: `localhost:8000`, `localhost:5500`, and the deployed domain
- The token is never committed — `.gitignore` excludes `config.local.js`
- A template `config.local.example.js` is provided for new clones

## Data

The application loads `payload_live.json` from `../07_reports/api_payloads/` (via the ETL pipeline)
or falls back to the local `payload_live.json` if the ETL path is unavailable.
Falls back to hardcoded defaults if no payload is found.

## Browser support

Modern browsers with ES2015+ and native ES Modules support. Tested on Chrome, Edge, Firefox.
